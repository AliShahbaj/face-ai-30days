# Face AI – 30 Days Learning Journey

A practical 30-day journey to learn Face Detection, Face Recognition, and Computer Vision using Python.

## Learning Goals

- Understand Computer Vision fundamentals
- Learn Face Detection and Facial Landmark Detection
- Understand Face Alignment
- Learn Face Embeddings and Similarity Matching
- Build Face Verification (1:1) systems
- Build Face Identification (1:N) systems
- Explore OpenCV and Deep Learning models

## Tech Stack

- Python 3.11
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook
- Git and GitHub

## Setup Instructions

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd face-ai-30days
```

Create a virtual environment:

```bash
python3.11 -m venv .venv
```

Activate it on macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
